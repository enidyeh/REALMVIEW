## 2026-10-10 改版要点（本轮）

1. **渲染根因修复**：`site.css` 的 reset 只把 `h1/h2/h3/p/ul/ol/dl/dd` 的 margin 归零，**漏了 `h4`**。
   站内大量卡片标题（案例名、达人名、栏目名、服务名、合作方式名）都是 `h4`，一直带着浏览器默认的
   `1.33em` 上下边距 —— 这就是之前反复感觉「行距太宽」的真正原因。现在 `h4/h5/h6` 一起归零。
   实测：案例标题到小标题的间距从 **26.6px → 4px**（就是 grid 的 `--s-1`）。
2. **板块标题行**：右侧中文标题字号提到 `--f-title`（30px），与英文板块名同级、同一行。
3. **案例卡**：行高收紧到接近单倍（标题 1.05 / 小标题 1.2）。
4. **卖点轮播整体从 PROJECTS 挪到 ABOUT**（代码在 `App.tsx` 的 ABOUT 组内）。
5. **TALENTS**：
   - `Filters` / `Sort` 两个按钮删除；
   - 搜索框**真正可用**（输名字 / 平台即可过滤，回车或点右侧放大镜都行），无结果时提示带关键字；
   - 底部的 `MORE` 换成**左右圆形箭头 + 中间页码**（`01 / 02`），每页 4 位、桌面正好一行；
     分类或关键字一变就回到第 1 页，只有一页时不显示翻页控件；
   - 名字改成随视口微调的字号（`clamp(22px, 1.5vw + 8px, --f-title × 0.94)`），
     保证四列布局下最长的名字（Aaron Liebregts）在所有宽度都不折行。
6. **INSIGHTS**：四张栏目卡的顶线不再用灰阶四档——**默认统一浅灰（`--grey-4`），只有被点中的那张变黑**；
   卡片下方那句「当前栏目：…」已删（选中态已经能说明）。
7. **首屏**：洛杉矶继续左移到 `x=330`。

## 技术栈与命令

Vite + React 19 + TypeScript，独立于其它项目，自带一套设计令牌（`src/styles/tokens.css`）。

```bash
npm install
npm run dev      # http://localhost:5273（固定端口，避免与 5173 的项目冲突）
npm run build    # tsc -b && vite build → dist/
npm run lint     # eslint .
npm run preview  # 预览生产构建，端口 5274
```

构建后的 `dist/` 是纯静态文件，可直接部署到任意静态托管。

## 设计系统 v2「制图 / SPEC」

方向：黑白灰细线为主 + 网格纸底 + 金属银点缀；颜色只作为功能性标记出现，不做大面积色块。
参考语言：细线球体/连接线的标志、方格纸上的卡片排版、金属质感档案页签与条码。

- 结构靠 1px 细线：区块用 `--rule`，分隔用 `--line`，需要看清的线用 `--line-2`；圆角一律为 0。
- 底：白 `--paper` / 次白 `--paper-2` / 灰 `--paper-3`，body 铺 24px 方格（`--grid`）。
- 墨：`--ink` / `--ink-2` / `--ink-3` 三档灰。
- 颜色：**当前为全灰阶**（2026-10-09）。`--red / --blue / --green / --yellow` 四个语义名保留，
  值统一压成黑 / 灰：`--red` 与 `--yellow` = 黑，`--blue` 与 `--green` = 深灰，
  三个 wash 换成 `--paper-2 / --paper-3`。**以后要加回颜色，只改 `tokens.css` 里这七行的值即可，`site.css` 不用动。**
- 需要「同形不同值」的标记改用灰阶四档：`--ink`(#0d0d0d) / `--grey-2` / `--grey-3` / `--grey-4`
  （四个内容栏目的顶线与方块即为此四档）。
- 金属银 `--silver` 只用在一处：合伙人卡片的头部。
- 字体三族：等宽（标签、编号、数据）、黑体（标题与正文）、宋体（保留未用）。
  标题已从宋体改为黑体 600 + 负字距。
- 字号只允许五级：`--f-display / --f-title / --f-sub / --f-body / --f-meta`，窄屏在 `tokens.css` 统一降级。
- 交互反馈用**硬阴影**（`--shift` / `--shift-red` / `--shift-yellow`，无模糊），不用柔和投影。
- 圆角只有两个例外：卖点轮播进度条与 Filters / Sort 胶囊用了 `border-radius: 999px`
  （按项目方给的参考截图做的），其余一律保持 `--radius: 0` 锐角。
- 粗线现状：全站只剩下 `INSIGHTS` 四张内容栏目卡的 3px 灰阶顶线（刻意保留，"同形不同值"），
  区块之间的横贯线现在是 1px 细线。
- 「能力与作品」下方的能力标签行与页脚说明文案已按项目方要求删除
  （`data/work.ts` 的 `capabilities` / `workNote` 已移除），该区块只剩 2×2 案例卡与卖点轮播；
  `#work` 的区块头用 `.sec-head.is-plain` 去掉了下边框。
- 板块之间的 **3px 粗分割线已全部删除**（`.grp` 不再有 `border-top`，2026-10-09）。
